# 🔐 Log Brute Force Detector

Script em Python para análise de logs e detecção de possíveis ataques de brute force.

## 🧠 Funcionalidades

- Leitura de arquivos de log
- Identificação de tentativas de login falhadas
- Contagem de tentativas por IP
- Geração de relatório automático

## 🛠 Tecnologias utilizadas

- Python

## 🎯 Objetivo

Projeto desenvolvido para prática de análise de logs e fundamentos de cibersegurança.

## 📊 Exemplo de saída

IPs suspeitos:

192.168.0.10 -> 3 tentativas  
192.168.0.30 -> 4 tentativas
