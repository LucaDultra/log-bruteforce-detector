# 🔐 Log Brute Force Detector

Projeto desenvolvido para detectar possíveis ataques de brute force através da análise de logs.

## 🚨 Problema

Sistemas expostos na internet podem sofrer diversas tentativas de acesso indevido, como ataques de brute force, onde um atacante tenta múltiplas combinações de senha.

## 💡 Solução

Este script em Python analisa arquivos de log e identifica IPs com múltiplas tentativas de login falhadas, ajudando na detecção de comportamentos suspeitos.

## ⚙️ Funcionalidades

- Leitura de logs
- Identificação de falhas de login
- Contagem de tentativas por IP
- Geração de relatório automático
- Definição de limite de tentativas

## 🛠 Tecnologias

- Python

## ▶️ Como executar

python detector.py
